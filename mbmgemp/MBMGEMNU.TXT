ge-next RELEASE NOTES

ge-next is an updated and expanded version of the classic Galactic Empire
by Mike Murdock.

https://manicpop.org/ge-next  https://github.com/manicpop/ge-next
https://discord.gg/SqhYmZvWsn  anthony@manicpop.org
Please contact with me thoughts and suggestions.

This is the first test build for the 0.3 series of ge-next.

There is new "overwarp" behavior and new jamming behavior.
Please try them out.

Scans have been completely overhauled.
Make sure to read HELP SET and set your desired SET SCAN.
It defaults to FULLNAMES on a fresh game, but if you are updating a 0.2 game
it will not be set correctly.
Please test all the different scan mdoes.

Ship letters showing up as '?' should be fixed. Let me know if you see any
appear.

There is a new paging system for your list of ships when you start the game.
If you have over 15 ships, the first 15 will be displayed, and you can then
use 'N' and 'P' to navigate the pages of ships. This fixes memory overflow
errors and also makes you list a little more manageable.

The game will no longer try (and fail) to create sectors when the planet
database is full, which will keep odd "phantom planets" from appearing.
